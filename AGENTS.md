# RazorRecover — Agent Guidance

RazorRecover is a safety-aware payment recovery system built with Next.js 14 App Router, TypeScript, and Tailwind CSS.

- **Primary Entry Point**: `src/app/cases/page.tsx` (Operational Recovery Dashboard)
- **Core Pipeline**: `src/lib/recovery/` (7-Step Decision & Safety Pipeline)
- **Testing**: `npm test` (Vitest)
- **Build**: `npm run build` (Next.js)
