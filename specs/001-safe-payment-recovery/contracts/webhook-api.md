# Webhook & Razorpay Integration API Contract

## 1. Webhook Ingestion Endpoint

**Endpoint**: `POST /api/webhooks/razorpay`  
**Headers**:
- `X-Razorpay-Signature`: HMAC SHA256 signature generated by Razorpay.

**Request Body** (Standard Razorpay Webhook Payload):
```json
{
  "entity": "event",
  "account_id": "acc_00000000000001",
  "event": "payment.failed",
  "contains": ["payment"],
  "payload": {
    "payment": {
      "entity": {
        "id": "pay_Lxyz1234567890",
        "amount": 50000,
        "currency": "INR",
        "status": "failed",
        "order_id": "order_Labc9876543210",
        "method": "card",
        "error_code": "BAD_REQUEST_ERROR",
        "error_description": "Payment failed due to insufficient funds.",
        "created_at": 1700000000
      }
    }
  },
  "created_at": 1700000005,
  "event_id": "event_Levt1122334455"
}
```

**Responses**:
- `200 OK`: `{"status": "processed", "case_id": "uuid", "integrity_state": "TRUSTED"}`
- `200 OK` (Duplicate): `{"status": "ignored", "reason": "DUPLICATE_EVENT"}`
- `400 Bad Request`: `{"error": "INVALID_SIGNATURE"}`
- `500 Internal Server Error`: `{"error": "PROCESSING_FAILED"}`

## 2. Razorpay API Integration Calls (Test Mode)

### 2.1 Create Payment Link (Recovery Execution)
- **Endpoint**: `POST https://api.razorpay.com/v1/payment_links`
- **Authentication**: Basic Auth (Key ID & Key Secret)
- **Payload**:
```json
{
  "amount": 50000,
  "currency": "INR",
  "accept_partial": false,
  "description": "Payment Recovery Link for pay_Lxyz1234567890",
  "customer": {
    "name": "Merchant Customer",
    "email": "customer@example.com"
  },
  "notify": {
    "email": true,
    "sms": false
  },
  "reminder_enable": true,
  "notes": {
    "recovery_case_id": "uuid",
    "original_payment_id": "pay_Lxyz1234567890"
  }
}
```

### 2.2 Payment State Fetch (Reconciliation Engine)
- **Endpoint**: `GET https://api.razorpay.com/v1/payments/{payment_id}`
- **Authentication**: Basic Auth
- **Response**:
```json
{
  "id": "pay_Lxyz1234567890",
  "entity": "payment",
  "amount": 50000,
  "currency": "INR",
  "status": "failed",
  "order_id": "order_Labc9876543210",
  "method": "card",
  "captured": false,
  "error_code": "BAD_REQUEST_ERROR",
  "created_at": 1700000000
}
```
